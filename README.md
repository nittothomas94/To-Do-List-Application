📁 Frontend – To-Do List Application

✅ Features Implemented:

- Developed using React.js with Vite for fast development.
- Integrated Tailwind CSS for responsive and modern UI styling.
- User authentication pages: Login and Signup.
- Task management:
  - Add new tasks
  - View all tasks
  - Delete tasks
  - Sort tasks by time
- Axios used for connecting frontend with backend APIs.
- Responsive design using Tailwind's utility classes.


🧪 Run Locally:

1. Navigate to the frontend folder:
   cd frontend
2. Install dependencies:
   npm install
3. Start the development server:
   npm run dev
